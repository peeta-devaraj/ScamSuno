## Release gates

- [x] **F01 — Entry and navigation.** Deployed root returned 307 to `/v3?l=en`. Authorized V3 and V2 pages returned 200; English was selected and the V2-to-V3 link preserved Telugu. Narrow-viewport fixture coverage verifies the full switch and layout. V1 is explicitly marked as the fallback.
- [x] **F05 — Scenario integrity.** Server-owned legitimate, fraudulent and ambiguous scenarios drive the caller and debrief. The caller model chooses from allowed contextual responses; it does not author arbitrary lines. Multilingual contradiction, negation and invention regressions passed. The public session projection withholds the assignment during the call. Independent verification establishes the status of the simulated notice without authenticating the caller. The debrief reveals the category after End and bases feedback on observed behavior; uncertainty and untested criteria do not count as successes or failures. No blocking unfinished code marker was found in the inspected V3 routes, service or UI. [Caller](../../src/server/v3/caller.ts) · [Approved dialogue](../../src/server/v3/approved-dialogue.ts) · [Controller](../../src/server/v3/controller.ts) · [Public session](../../src/server/v3/public-session.ts).
- [x] **F06 — Credential minimization for tested inputs.** Synthetic credential paraphrases, numbers, quoted values and refusals were tested across supported languages. Model and persistence paths apply separate masking/withholding; voice/typed/button provenance is retained. This is bounded detection, not a guarantee for arbitrary secrets. Recorded audio goes to Gnani for transcription; audio is handled in memory by the app, and transcripts can still contain ordinary text. Testers must use fictional data. [Privacy filter](../../src/server/v3/privacy.ts) · [Retention](../../src/server/v3/sessions.ts).
- [x] **Session and admin boundaries tested.** Server-side environment credentials, signed transcript proof bound to owner/session/turn, cross-origin rejection, fixture rejection in deployed environments and End/cancellation paths passed relevant regressions. With Vercel protection satisfied, both admin pages rejected requests lacking app credentials (401). Signed-out V3 redirected (302). These checks are limited to the observed routes and tests; they are not a penetration test. [HTTP evidence](../audit/evidence/final-gate-preview.json) · [Voice routes](../../src/server/v3/voice-http.ts).
