## Feedback and privacy follow-up

- **Deployed check, November 9:** A Tamil synthetic session returned no debrief at start and a four-item debrief after authenticated End. Repeating End returned the same debrief. The unauthenticated request for that same session got 401 and a cross-origin request got 403. A separate signed-out Telugu browser run displayed all four feedback items. Browser TTS was blocked deliberately and no reply was submitted, so only ending the call was marked as observed; the other criteria were not tested. - **Public boundary checks:** Both operator routes returned 401 signed out. No hidden scenario marker or token-like value matched in the sampled Tamil/Telugu HTML and nine public JavaScript chunks. Legacy V1/V2 speech endpoints on the V3 host returned 503. Classic health confirmed 60 clips across four languages and microphone input disabled. The dependency registry reported no known advisories for the installed production dependency graph at the time of the check. [Legacy checks](../audit/evidence/feedback-security/legacy-routes.json) · [Registry results](../audit/evidence/feedback-security/dependency-audit.json)
- **Local release changes:** Session-scoped HttpOnly cookies stop a second tab from replacing the first call's feedback access. The server grants five minutes for feedback after the eight-minute turn limit, without extending paid turn admission. An incomplete End result offers a retry, and a successful debrief brings the heading into view. Old owner cookies are still accepted for active sessions during rollout. A rollback to an older build will not recognize new session cookies.
- **Privacy change, local only:** V3 retains authored caller captions, reply origin and validated decision labels, with empty fields in place of participant text and evaluator quotations. Earlier text is not sent to the model on a later turn. New writes and reads enforce this rule without a schema change. Older stored records and backups are not retroactively erased; the [runbook](../audit/V3_VOICE_LAUNCH_RUNBOOK.md) covers cleanup. The landing disclosure identifies Gnani as the speech transcriber in all four languages. Filtered current replies still go to the hosted model. Use fictional information.
- **Local verification:** All 280 tests, type checking, the production build and the shipped-audio integrity check passed. The browser suite had 29 passes and one failure from an alert selector that also matched Next's route announcer. After narrowing it, the feedback retry and narrow-viewport browser regressions passed.
