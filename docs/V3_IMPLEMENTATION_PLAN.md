## Architectural boundaries

Keep hidden internal state in server modules. V2's full-session response is unsuitable for V3: construct a separate public projection. Do not reuse V2's practice-code progression or two-refusal termination as the V3 controller. Keep scenario assignment independent of participant behavior. The evaluator observes behavior and verified events without hidden caller truth. Generated text passes safety checks before synthesis; numerical grades are unnecessary for the initial rubric.

V3 is feature-flagged off by default. Authenticated End must remain possible after disabling. V3 records must be additive and remain after rollback. No V2 schema replacement, no shared Preview variable changes, and no real provider tests before current credit admission is verified.
